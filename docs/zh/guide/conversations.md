# 会话

会话是一切内容诞生的地方。从一个问题、一条粗略的笔记或一个文件开始，Zett 会边工作边回答，其中有价值的部分会成为你可以审阅并保留的[产物](artifacts.md)。在 Chrome 里阅读？你同样可以在[页面旁边](chrome-extension.md)完成这些事。

## 开始一个会话 {#start-a-conversation}

1. 在侧边栏选择**新建会话**，或在产物库中选择**新建卡片**。
2. 在输入框中选择一个模型。如果列表为空，请先在[设置](settings.md#ai-providers)中添加一个 Provider。
3. 请求一个小而具体的结果，例如：“把这些笔记整理成一张简洁的卡片，包含标题和两句话的摘要。”

Zett 会边写边把回答流式显示出来。它创建的所有内容，例如卡片、文章或幻灯片，都会作为草稿出现在聊天旁边的面板中，等你审阅。

侧边栏列出的是你在这里发起的会话。[定时任务](scheduled-tasks.md)的运行记录和来自[通信渠道](channels.md)的聊天，会在各自的页面中列出。

把鼠标悬停在会话上可以重命名或删除它。点击标题可以就地重命名。

::: warning 删除会话会一并删除它生成的内容
删除会话会移除它的消息、文件，以及在其中创建的所有产物，包括已经保存到产物库的那些。
:::

## 输入框 {#the-composer}

| 控件 | 作用 |
| --- | --- |
| **模型** | 回答下一条消息所用的 Provider 和模型。每个会话会记住自己的选择。 |
| **思考** | 模型回答前的推理力度：**关闭**、**低**、**中**或**高**。 |
| **Shell** | **审核**会在运行 Shell 命令前询问你；**全部放行**则直接运行命令。 |
| **Enter** | 发送消息；如果 Zett 还在回答，则将消息加入队列。**Shift + Enter** 换行。 |
| `/` | 打开此会话可用的命令列表。 |
| `@` | 引用此会话中的文件或产物。 |

你可以把图片和文件粘贴或拖放到消息框中。能识别图片的模型会直接读取图片，Zett 在工作时也可以打开附加的文件。允许上传的最大文件大小在[设置](settings.md#limits)中配置。

输入 `@` 可以指向这里已有的内容，例如“把 @reading-list.md 和 @Local-first beats sync 做个对比”。菜单中会列出此会话的文件和产物。

## Zett 回答时 {#while-zett-is-answering}

你可以继续输入。在一轮回答进行时按 **Enter**，消息会加入队列，而不会打断当前回答。在队列中你可以：

- 拖动消息来调整顺序，
- 删除消息，或
- 选择**引导**，立即把消息交给当前这一轮，适合“改用第二个文件”这类补充。

以 `/` 开头或使用了 `@` 的排队消息，始终会等到属于自己的那一轮再执行。

有时 Zett 需要你做出决定。它会显示一个带若干选项的问题，另有**其他**供你输入自己的答案；选择一项后点击**继续**。在你回答之前，这一轮会一直等待。

## 审批 Shell 命令 {#approving-shell-commands}

当 **Shell** 设为**审核**时，Zett 想运行的命令会暂停在一张审批卡片上，卡片会显示完整的命令及其允许运行的时长。

- **执行**：运行这一次。
- **中止**：拒绝该命令，Zett 会在没有它的情况下继续。
- 在选择**执行**之前勾选**始终允许这条完全相同的命令**，之后在此会话中，同一条命令将不再询问。

每个会话保留各自的设置，你可以在发送任何消息之前修改它。

[定时任务](scheduled-tasks.md)和[通信渠道](channels.md)是在无人值守的情况下运行的，所以它们会直接运行命令而不询问。请只在你放心无人看管的模型和提示词上使用它们。

## 工作台 {#the-workspace}

聊天旁边的工作台会汇集此会话产出的内容。

- **产物**以简短摘录或缩略图的形式列出。选择一项即可在列表下方预览。拖动列表与预览之间的分隔条可以调整两边的空间，也可以聚焦分隔条后用 **↑** 和 **↓** 键调整。
- 每个产物都有**保存**（或**更新**）、**编辑**和**删除**。**全部保存**会保存所有有待处理改动的产物；如果其中某个无法保存，其余的仍会保存，Zett 会告诉你哪一个失败了。
- 图片、PDF 和图表会在更大的阅读器中打开。按 **Esc** 关闭。
- **资源**列出此会话保留的参考文件。参见[资源](assets.md)。

## 轨迹与使用情况 {#trace-and-usage}

会话标题栏中的图标可在**工作台**和**轨迹**之间切换。轨迹会显示每一轮的每一步：所用的模型和思考级别、Zett 使用的每个工具及其输入和结果、每一步的耗时，以及消耗的 Token。

两轮之间的分隔线会显示这一轮的开销：输入和输出 Token、推理、缓存使用情况和速度。点击它可以跳转到发起这一轮的消息。

输入框旁边的圆环显示会话记忆的占用程度。当较长的会话接近上限时，Zett 会总结较早的轮次，使会话得以继续。你也可以在轨迹中看到这一过程。

## 在别处继续 {#continue-elsewhere}

你可以使用 [Chrome 中的 Zett](chrome-extension.md) 在网页旁边工作，也可以连接[通信渠道](channels.md)，在手机上与 Zett 对话。它们各自保留自己的会话。无论你创作了什么，何时发布都由你决定：参见[产物与产物库](artifacts.md)。

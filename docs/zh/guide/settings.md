# 设置与本地数据

选择侧边栏的**设置**。对话框会在工作台上方打开，包含**使用情况**、**模型服务**和**限制**几个部分。点击 **×**、按 **Esc** 或点击对话框外部即可关闭，你会回到刚才的位置。

## 语言 {#language}

用侧边栏底部的语言菜单在 **English** 和**中文**之间切换。这个选择会记录在当前浏览器中。

## AI Provider {#ai-providers}

Zett 不自带模型。Provider 是与某个模型的一条连接：包括名称、服务、模型和你的 API Key。你可以添加多个，把两个模型或两个端点并列保存，然后为每个会话、任务或渠道各选一个。

1. 打开**设置 → 模型服务**，选择**新建 Provider**。
2. 起一个你认得出的**连接名称**，例如“DeepSeek chat”。
3. 在 **Provider** 下选择服务类型，然后填写**模型**，例如 `deepseek-chat`。
4. 粘贴你的 **API Key**。只有当你的服务需要自定义地址时，才填写 **Base URL**。
5. 保存。该 Provider 会出现在每个会话的**模型**菜单中。

| Provider | 适用场景 |
| --- | --- |
| **OpenAI**、**Anthropic**、**Google Gemini**、**DeepSeek**、**Ollama** | 直接使用这些服务。Ollama 在你自己的电脑上运行模型。 |
| **OpenAI compatible**、**Responses compatible** | 任何提供 OpenAI 风格或 Responses 风格 API 的其他服务。 |

你的 API Key 会在这台电脑上加密保存，之后不会再显示。编辑 Provider 时，把密钥留空即可沿用已保存的密钥。

仍被会话、定时任务或渠道使用的 Provider 不能被停用或删除。请先把它们切换到其他 Provider。

## 限制 {#limits}

| 设置项 | 控制内容 |
| --- | --- |
| **每条消息图片数** | 一条消息最多可以带多少张图片。 |
| **每轮模型步数** | Zett 在必须给出回答之前最多可以执行多少步，例如工具调用。 |
| **最大文件大小** | 可以上传或粘贴的最大文件。 |
| **压缩上下文阈值** | 会话长到什么程度时，Zett 会总结较早的轮次。 |
| **保留最近上下文** | 压缩时，最近的对话有多少会原文保留。 |

新消息会立即使用修改后的限制。已经在运行的回复会按开始时的限制完成。

## 使用情况 {#usage}

**使用情况**展示你随时间使用模型的情况：每个模型的请求数、输入和输出 Token、推理以及缓存使用量，并附有每日活动日历。数据由这台电脑上你自己的历史记录统计得出。如需查看某个会话的详细信息，请打开它的**轨迹**。

## 你的数据存放在哪里 {#where-your-data-lives}

Zett 保存的所有内容——你的产物库、会话、文件、Provider 和设置——都存放在这台电脑上的一个文件夹中：`~/.zettelekasten`。

- **备份**这个文件夹即可保留你的工作台，恢复它就能找回全部内容。
- **迁移**：在运行 `zett start` 之前，把 `ZETT_STORAGE_ROOT` 设置为另一个文件夹。
- **日志**在其下的 `logs` 文件夹中，出问题时会派上用场。

::: info 哪些内容会离开你的电脑
你的文件夹保存在本地，但你发给模型的消息会发送到你选择的 Provider，已连接的聊天应用也会与其自身的服务交换消息。不要发送你不希望它们处理的内容。
:::

删除会话时，也会删除它创建的文件和产物。仍有会话在使用的全局资源不能被删除。

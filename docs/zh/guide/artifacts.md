# 产物与产物库

产物是指在会话滚走之后仍值得回头再看的内容。你可以让 Zett 生成简洁的卡片、较长的文章、图片、幻灯片或 LaTeX 论文，然后决定哪个版本应该进入你的产物库。

| 类型 | 说明 | 须知 |
| --- | --- | --- |
| **卡片** | 一条简短的 Markdown 笔记 | 可标记为笔记、想法、引用、待办或参考 |
| **文章** | 长篇 Markdown 写作 | 包含标题、可选的副标题和正文 |
| **图片** | 带说明文字的图片 | 来自网页链接或会话中的文件 |
| **幻灯片** | Markdown 幻灯片 | 支持封面、全屏演示和 PDF 预览 |
| **LaTeX PDF** | 编译好的论文 | 使用你电脑上的 LaTeX 工具构建；源文件由你保留 |

## 创建产物 {#make-one}

在[会话](conversations.md)中提出要求：“根据这个想法做一张卡片”“把这些笔记整理成一份十页的幻灯片，用于团队午餐分享”，或“起草一篇关于笔记同步的 LaTeX 论文，附上引用”。产物库中的**新建卡片**会打开一个全新的会话，专门用于此。

你可以明确指定形态：卡片的类型、幻灯片的页数、想要的标签，或论文应包含的章节。之后你也可以要求修改（“再短一点”“拆分第三页”“引用第二个来源”），Zett 会编辑同一个产物，而不是新建一个。

## 先是草稿，再有意发布 {#draft-first-published-on-purpose}

在你确认之前，任何内容都不会进入你的产物库。

1. 新产物会作为**草稿**出现在会话中。
2. **保存**会把它发布到产物库。
3. 之后 Zett 修改它时，改动会作为草稿放在已发布版本旁边等待处理，产物库仍显示已发布的版本。
4. **对比**会逐字段比较两个版本，并高亮显示变化之处。**更新**会发布这次改动。

会话产物列表中的每个产物都会通过外观和徽标显示它离“已保存”还有多远，因此颜色不是唯一的提示：

| 外观 | 徽标 | 含义 |
| --- | --- | --- |
| 琥珀色虚线外框 | **未保存** | 从未保存，仍是草稿 |
| 左侧蓝色竖条 | **有未保存修改** | 之前保存过，但有更新的草稿 |
| 朴素外观，绿色标记 | **已保存** | 已保存，内容最新 |

打开的编辑器会在顶部重复这个状态，并在持有尚未存储的修改时显示**编辑中**。工作台中的**全部保存**会一次发布所有待处理的产物。如果其中某个无法保存，其余的仍会保存，Zett 会告诉你哪一个失败以及原因。

Zett 自己无法发布任何内容，只有你才能保存。

## 编辑 {#edit}

- **在会话中。**选择一个产物进行预览，然后使用它所在行的**编辑**。用**对比**检查你的修改，再用**保存**或**更新**发布。图片和 PDF 有各自的控件。
- **在完整编辑器中。**从会话或产物库中的卡片打开它，即可并排查看源码和预览。对于 Markdown，两个窗格会同步滚动；幻灯片和 PDF 则显示渲染后的页面。按 **⌘S** 保存。
- **在产物库中。**编辑从产物库打开的卡片，会直接修改已发布的版本。

## 跟踪卡片状态 {#track-a-cards-status}

三种卡片类型各有自己的状态：

| 卡片类型 | 状态 | 点一下标记 |
| --- | --- | --- |
| **待办** | 待办、进行中、搁置、已完成、已取消 | 完成任务，或重新打开已完成的任务 |
| **想法** | 已记录、探索中、已采纳、已放弃 | 没有动作：采纳一个想法是一个决定，请用菜单 |
| **参考** | 未读、在读、已读 | 标记为已读，或再改回未读 |

笔记和引用没有状态。

- 点击标题前的标记可一键切换；点击状态胶囊可在该卡片类型的所有状态中任选。
- 状态属于卡片本身，而不是它的文本。更改立即生效：不会产生草稿，不需要保存，也不会改变版本号。
- 更改卡片类型时，卡片会得到新类型的第一个状态，除非它当前的状态仍然适用。
- 每种状态外观不同：新记录的卡片顶部有一条横条，进行中的卡片边缘有竖条，搁置的是虚线边缘，已完成、已采纳或已读的带淡绿色底，已取消或已放弃的会淡化并给标题加删除线。
- 在产物库中，**状态**一行会在三种类型中只保留处于所选状态的卡片，可以多选。
- Zett 可以读取状态，并用 `set_card_status` 修改。它只会在你做出决定时才关闭任务或采纳想法。Chrome 面板和 `zett artifact mark` 也能修改。

## LaTeX 论文 {#latex-papers}

论文是一个小型的 LaTeX 项目，而不是单个文本字段。Zett 会编写源文件，用你电脑上安装的 LaTeX 工具编译，并展示生成的 PDF。它会用版本控制管理该项目并记录每次改动，因此每个已保存的 PDF 都对应一组确定的源文件。

如果你自己编辑源文件，请在保存前提交你的改动。Zett 只会保存源文件已全部提交的论文；否则它会列出仍有改动的文件，方便你知道该提交哪些。

## 图片 {#images}

图片来自网页链接，或来自此会话中的文件。若要使用你自己的图片，请在会话中添加附件，并让 Zett 据此创建图片产物。如果图片文件缺失，Zett 不会保存该图片。

请在编辑器中为每张图片填写说明文字和替代文本，让读者和屏幕阅读器知道图片内容。

## 产物库 {#the-library}

侧边栏中的**产物**会打开你的产物库：你已发布的所有内容。

- 按 **⌘K**（Windows 和 Linux 上为 **Ctrl+K**）搜索标题和内容。
- 按类型筛选：**全部**、**卡片**、**文章**、**幻灯片**或 **PDF**。
- 在侧边栏中选择一个分类，只显示打了该标签的内容。
- 打开一张卡片即可进入完整阅读器，其中有**编辑**、全屏预览、幻灯片的**演示**、返回其来源会话的链接，以及**删除**。

## 标签 {#tags}

标签构成一棵树，例如 `Technology/Python`，在侧边栏中显示为**分类**。

- 点击**分类**旁边的 **+** 添加标签。输入路径时，缺失的父级也会一并创建。
- 把产物库中的卡片拖到某个分类上，即可为它打上该标签。
- 让 Zett 为生成的内容打标签。它的建议只会在你保存产物时才生效，保存前你可以在编辑器中取消勾选其中某个建议。
- 保存绝不会移除你自己添加的标签。
- 删除标签会把它从所有带有该标签的条目中移除。

全局资源有自己的分类；参见[资源](assets.md#classify-a-file)。

## 从会话之外添加 {#add-from-outside-a-conversation}

脚本、ChatGPT，以及 Claude Code 或 Codex 之类的编程智能体，都可以直接把卡片、文章和幻灯片添加到你的产物库。参见[命令行](command-line.md#add-to-the-library)。

## 让 Zett 学会你的风格 {#teach-zett-your-style}

Zett 为每个产物遵循一份写作指南：卡片如何分节，图表和封面如何书写，幻灯片如何分页。这份指南是位于 `~/.zettelekasten/skills/zett-artifact-syntax/SKILL.md` 的普通文件，你可以编辑它来改变 Zett 的写作方式。Zett 会在首次启动时创建它，并且绝不会覆盖你的修改；删除该文件后，下次启动时会恢复原版。

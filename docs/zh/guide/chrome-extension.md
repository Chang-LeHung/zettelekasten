# 在 Chrome 中阅读与保存

Zett 扩展会在你正在阅读的页面旁边打开一个会话。你可以询问页面内容，把有用的部分整理成卡片或文章，并在不切换标签页的情况下保存到产物库。面板悬浮在页面右侧：拖动顶部的条带可以移动它，拖动任意一角可以调整大小。

::: info 从源码安装
该扩展尚未上架 Chrome 应用商店。你需要从本仓库构建，并自行加载到 Chrome 中，只需一分钟。
:::

## 安装扩展 {#install-the-extension}

1. [安装并启动 Zett](../index.md#quick-start)，并确认浏览器能打开 `http://127.0.0.1:6280`。
2. 在你的仓库副本中构建扩展：

   ```bash
   npm --prefix zett3rd/chrome-extension install
   npm --prefix zett3rd/chrome-extension run build
   ```

3. 打开 `chrome://extensions`，开启**开发者模式**，然后选择**加载已解压的扩展程序**。选择 `zett3rd/chrome-extension/dist` 文件夹，而不是它的上一级文件夹。
4. 打开任意网页，点击工具栏中的 Zett 图标。如果 Zett 运行在其他地址，请在面板的**设置**中修改。

之后要更新扩展，请重新构建，然后在 `chrome://extensions` 中点击其卡片上的**重新加载**。

扩展需要获得你所用页面的访问权限，这样才能在你发送消息时读取当前页面。页面内容会发送到你自己的 Zett，再由它转发给你选择的模型服务商。

## 与页面协作 {#work-with-a-page}

试试“用三点总结这个页面”，或“根据第二部分的论点做一张卡片”。回答会流式显示在面板中。

- Zett 创建的所有内容都会显示在面板中，并带有**保存**按钮。在 **•••** 菜单中选择**全部保存**，可一次保存所有待处理的内容。
- 让 Zett 为生成的内容打上标签，保存时它会把结果归入你的分类。
- 可以通过选择器、粘贴或拖放到消息框来添加图片。
- **Enter** 发送；**Shift + Enter** 换行。
- Zett 回答期间发送的消息会在队列中等待。你可以用**引导**把它交给当前回答，也可以删除它，或让它在下一轮运行。
- **停止**会结束当前回答并清空队列。

每个标签页和页面都有自己的会话。回到某个页面时，它的会话仍然在；跳转到同一页面的 `#section` 不会开启新会话。使用**新聊天**可以在该页面上重新开始，也可以从面板顶部选择最近的会话。

## 让 Zett 使用页面 {#let-zett-use-the-page}

页面连接期间，Zett 可以读取页面上的内容，并在你许可后在页面上点击、输入、按键或拖动。每个操作都会先询问你：

- **仅此一次允许**：只放行这一次操作。
- **本会话始终允许**：在本会话的后续操作中不再询问。你可以在 **•••** 菜单中撤销。
- **拒绝**：拒绝该操作，Zett 会在没有它的情况下继续。

请让 Zett 填写或提交内容时尽量表述精确。有些网站会忽略自动化输入，因此可以让 Zett 重新读取页面，确认实际发生了什么。**停止**不会撤销已执行的操作：已填写的表单可能已被网站保存。Zett 绝不会在页面上运行它自己的脚本。

## 面板无法连接时 {#if-the-panel-cannot-connect}

1. 运行 `zett status`，确认 Zett 能在面板中设置的地址打开。
2. 在面板的 **•••** 菜单中选择**连接页面**重试。
3. 重新构建扩展后，点击其卡片上的**重新加载**，并重新打开页面。

如果页面连接一直不可用，Zett 仍可根据页面摘录作答，但在这次回答中无法读取实时页面，也无法对其执行操作。

接下来，关于输入框和工作台，请参见[会话](conversations.md)；关于草稿和保存，请参见[产物与产物库](artifacts.md)。

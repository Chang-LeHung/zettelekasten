# 资源

资源是 Zett 工作时用到的文件和笔记：一篇你正在总结的论文、一条想让它阅读的链接、一张截图、一段代码。根据需要保留的时间长短，决定把它放在哪里。

| | 会话资源 | 全局资源 |
| --- | --- | --- |
| 使用范围 | 单个会话 | 任意会话 |
| 在哪里找到 | 工作台的**资源**栏 | 侧边栏的**全局资源** |
| 如何添加 | 添加文本笔记或链接、上传文件，或直接粘贴到资源栏 | 上传一次，之后在需要的地方导入 |
| 删除 | 随时可以删除 | 仍有会话在使用时不能删除 |

## 会话资源 {#session-assets}

会话旁边的**资源**栏存放该会话的参考资料：笔记、链接、文档、图片和代码。

- **添加文本笔记**和**添加链接**可以用文本或 URL 创建资源。
- **上传文件**，或把文件拖入、粘贴到资源栏，即可添加文件。
- 可以搜索资源栏，也可以按类型筛选：文档、图片、链接、笔记或代码。
- 需要更多空间时，用眼睛按钮隐藏或显示资源栏。

附加在消息上的文件略有不同：它们会出现在会话本身中，图片直接内嵌显示，Zett 也能读取，但不会列在**资源**栏里。

在输入框中输入 `@`，可以引用某个资源，而不必把内容粘贴进消息：“用五个要点总结 @paper.pdf”。

## 全局资源 {#static-assets}

**全局资源**是跨会话的文件库：你经常引用的论文、反复使用的模板、希望每份草稿都遵循的风格指南。

1. 在**全局资源**中上传文件。
2. 在任意会话中选择**导入全局资源**并选中它。会话引用的是文件库中的文件，而不是复制一份。
3. 只要还有会话导入着某个全局资源，Zett 就不会删除它，因此会话不会丢失自己依赖的文件。

你也可以让 Zett 把它生成的文件加入全局资源，例如“把导出的图表保存到我的全局资源的 Reports 下”。是否把它导入其他会话，仍由你决定。

可以按名称搜索全局资源，也可以按类型筛选。

## 为文件分类 {#classify-a-file}

全局资源有自己的**分类**树，与产物库的分类树相互独立。在这里创建的分类不属于产物库，即使两者同名也是如此，而且每棵树只统计自己的条目。

- 把文件拖到侧边栏的某个分类上，即可为它打标签。文件原有的标签会保留。
- 点击某个分类，只显示打了该标签的文件。

你也可以在终端中为文件打标签：参见[命令行](command-line.md#organize-with-tags)。

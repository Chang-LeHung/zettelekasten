# 通信渠道

通信渠道把 Zett 连接到聊天应用，让你可以用手机给同一个 Zett 发消息：发一张白板照片并让它做成卡片，转发一段语音，或者问问你这周保存了哪些关于某个主题的内容。

## 连接聊天应用 {#connect-a-chat-app}

1. 打开侧边栏的**通信渠道**，选择**连接**。
2. 如果有多个聊天应用可选，选择平台。
3. 给机器人起个名字，并选择负责回答其聊天的 Provider。
4. 选择**生成二维码**，用要连接的账号扫描二维码，并在手机上确认。
5. 如果应用显示了配对数字，把它输入到对话框中。
6. 渠道显示为**已连接**后，就会开始回复消息。

对话框会告诉你当前进行到哪一步：等待扫码、已扫码并等待你确认、等待输入配对数字，或正在连接。二维码五分钟后过期，过期后请重新生成。

可选的平台是随 Zett 安装的聊天插件。目前是**微信**，通过腾讯的个人微信机器人功能（微信机器人）接入。企业微信机器人不能替代它。

## 聊天与历史记录 {#chats-and-history}

每个单聊和每个群聊都有自己的会话，列在**通信渠道**下，而不是和你的其他会话放在一起。同一个聊天中的消息会按顺序回复。删除某个聊天的历史记录后，下一条消息会重新开始。

## 照片、语音与文件 {#photos-voice-and-files}

可以发送图片、语音、文件或视频，附不附消息都可以。Zett 会把每个文件的副本保存在该聊天对应的会话中。能看图的模型会直接读取受支持的图片；其他文件则可供 Zett 打开。模型能否理解某个具体文件，取决于你的 Provider。

一条消息最多可带 16 个附件，总大小不超过 256 MB。如果内容太大，聊天会收到说明，而不是悄悄丢掉文件。

## 渠道设置 {#channel-settings}

你可以为每个渠道选择：

- 回答其聊天的 **Provider** 和**推理强度**，从下一条消息起生效；
- 是否开启**允许远程对话使用编码工具**。

聊天消息运行时没有人守在屏幕前，所以命令会在没有审核卡片的情况下直接执行。除非你希望聊天消息能在这台电脑上运行命令，否则请保持**允许远程对话使用编码工具**关闭。

用**停用**暂停渠道，用**启用**恢复。渠道正在使用某个 Provider 时，该 Provider 不能被停用或删除。

## 出问题时 {#when-something-goes-wrong}

如果 Zett 无法回复某条消息，聊天会收到错误提示。请检查渠道是否仍显示**已连接**，以及 `zett status` 是否显示 Zett 正在运行，然后重新发送消息。如果登录失败或二维码过期，请从**连接**重新开始。

想在其他聊天应用里使用 Zett？通信渠道由插件提供，参见[通信渠道插件](../plugins/channel-plugins.md)。

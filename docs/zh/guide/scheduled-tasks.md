# 定时任务

定时任务会按计划向 Zett 发送同一条消息，即使没有打开浏览器也照常运行：周一的阅读摘要、每晚整理昨天的笔记、每月的项目总结。

## 创建任务 {#create-a-task}

打开侧边栏的**定时任务**并填写表单，也可以直接在任意会话中提出要求：“每周一 9:00，把我上周保存的内容总结成一张卡片。”两种方式创建的任务完全相同。

| 字段 | 含义 |
| --- | --- |
| **名称** | 任务列表中显示的标签。 |
| **计划** | 运行时间，用 cron 表达式表示，并指定解析它所用的时区，例如在 `Asia/Shanghai` 时区下用 `0 9 * * 1` 表示每周一 9:00。 |
| **Provider** | 由你的哪个 Provider 来回答。 |
| **消息** | 每次向 Zett 发送的内容。每次运行都从全新的会话开始。 |
| **推理强度** | **关闭**、**低**、**中**或**高**。 |
| **启用** | 任务是否按计划运行。 |
| **超时** | 一次运行最长可以花多久，超时会被停止。默认是十分钟。 |

让 Zett 创建任务时，请指明要使用的 Provider；Zett 可以查询你已有的 Provider，而不必猜测。

## 写一条能独立运行的消息 {#write-a-message-that-runs-alone}

任务运行时没有人可以回答问题，所以 Zett 无法停下来问你是什么意思。任务也不能在你的电脑上执行命令或修改文件：它只能使用 Zett 内部的内容，例如你的产物库、资源和分类。请把消息写成一条完整的指令：读什么、做什么、归档到哪里。

运行中创建的产物会直接保存到你的产物库，因为没有人在场点击**保存**。如果这次运行修改了你其他会话中的某个产物，这些修改仍会作为草稿等你审核。

## 运行、暂停与查看 {#run-pause-and-review}

列表中的每个任务都会显示下次运行时间、上次运行的结果以及可用操作。

- **立即运行**会马上开始一次运行，不改变原有计划。
- 关闭**启用**即可暂停任务。任务会保留设置和历史记录。
- 打开历史记录可以查看每次运行：何时运行、耗时多久、是否成功，失败时还会显示错误。每次运行都链接到对应的会话，你可以看到 Zett 做了什么，并打开它生成的内容。

只有你能删除任务。

## 任务没有运行怎么办 {#if-a-task-does-not-run}

1. 运行 `zett status`。服务器、调度器和工作进程都应显示 `running`。如果有一项不是，先运行 `zett stop`，再运行 `zett start`。
2. 检查任务是否已启用，以及下次运行时间在你选择的时区下是否符合预期。
3. 在[设置](settings.md)中检查它的 Provider 是否仍处于启用状态。
4. 打开任务的历史记录：已经开始但失败的运行会在那里显示错误。

Make something worth keeping.

Zett is a workspace for thinking with an AI on your own computer. Start from a thought, a file, or the page you are reading, turn it into a card, a deck, or a paper, and keep the version you choose in a folder you own.

Install Zett Read the docs

Free and open source. No account, no telemetry. macOS, Linux and Windows.

Talk it through. Keep what is good.

Ask for a card, an article, a slide deck, an image, or a LaTeX paper. The draft opens beside the chat, so you can read it, push back, and watch it change before anything is saved.

Drafts first
Nothing joins your library until you save. Later edits go to a draft you can compare with the saved version.
Steer while it works
Queue a follow-up, redirect the running turn, or stop it. Pick one of eight reasoning levels per conversation.
Any model you have
OpenAI, Anthropic, Gemini, DeepSeek, Ollama, or any compatible endpoint. Zett ships none of its own.

A library that is still yours in ten years.

Saved work lands in one searchable library with tags you define. Cards, articles, slides, and PDFs sit side by side, and any of them can go back into a conversation.

Collections
Nested tags you create, with counts. Filter by type or search across every body.
Point at things with @
Reference an artifact or an uploaded file from the composer and the assistant reads it on demand.
Plain files underneath
Markdown, PDF and PNG in a folder. Select several cards at once to remove them in a batch.

Let it work while you are away.

Put a prompt on a schedule and read the transcript later. Every run gets its own session, so unattended work never clutters your conversations.

Cron or plain intervals
Daily, weekly, monthly, with a time zone. Disable a task and its history stays.
Headless and logged
Prompt, tool calls and answer are recorded for every run, with no browser open.
Same library
Results are saved like any other artifact, ready for you in the morning.

The same assistant, from wherever you are.

In Chrome

Open Zett beside any page. It reads what you read. Filling a field or clicking a button waits for your Allow once, Decline, or Always allow, and sensitive fields are never touched.

In WeChat

Message Zett from your phone. A photo, a voice note, or a file arrives as a file, and the result is saved to your library while you are away from the desk.

In your terminal

Claude Code or Codex can file what it just finished straight into the library, through the CLI or MCP.

  --title "Release notes" --body-file notes.md

A plugin adds tools, hooks, slash commands, or a whole chat channel. Plugins are untrusted by design, so a broken one cannot take Zett down.

Everything lives in one folder.

Your library, conversations, files, and settings are ordinary files on your disk. Back them up, move them, or delete them like any other folder. The only network traffic is the model you chose, and a chat app only if you connect one.

The assistant cannot delete anything, or touch a web page, without your say-so.

~/.zettelekasten/

  • zett.dblibrary, tags, settings
  • agent.dbevery conversation
  • artifacts/papers and generated files
  • assets/files you added
  • skills/instructions you can edit
  • logs/when something goes wrong

Model keys are encrypted in this folder.

Two commands to start.

Python 3.10 to 3.14. Nothing to sign in to, and nothing running in the cloud.

$ uv tool install zettelekasten
$ zett start
Zett is running at http://127.0.0.1:6280
  1. Start it once. zett start serves the workspace in the background, and zett status checks on it.
  2. Bring a model. Add a provider in Settings. The key is encrypted and stays on your machine.
  3. Start talking. Ask for a card, review it beside the chat, and save it.

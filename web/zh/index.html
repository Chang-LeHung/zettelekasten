English 安装

做出值得 留下的东西。

Zett 是一个在你自己电脑上与 AI 一起思考的工作区。从一个想法、一份文件或正在阅读的网页出发，把它整理成卡片、幻灯片或论文，并把你选定的版本留在属于你的文件夹里。

安装 Zett 阅读文档

免费开源。无需账号，没有遥测。支持 macOS、Linux 和 Windows。

聊透它，留下好的。

让它做一张卡片、一篇文章、一套幻灯片、一张图，或一篇 LaTeX 论文。草稿会在聊天旁边打开，你可以阅读、反驳，并亲眼看着它改变，保存之前不会有任何东西进入产物库。

先出草稿
保存之前，什么都不会进入产物库。之后的修改只写入草稿，你可以与已保存的版本对比。
边做边引导
排队追加消息、中途改变方向，或直接停止。每个会话可以选择八档推理强度。
你有什么模型就用什么
OpenAI、Anthropic、Gemini、DeepSeek、Ollama，或任何兼容的接口。Zett 自己不带模型。

十年后，它仍然属于你。

保存下来的内容都在同一个可搜索的产物库里，带着你自己定义的标签。卡片、文章、幻灯片和 PDF 并排放着，任何一项都可以再回到会话里继续讨论。

分类
你自己建立的多级标签，附带数量。可以按类型筛选，也可以搜索所有正文。
用 @ 指向它
在输入框里引用某个产物或上传的文件，助手会在需要时再去读取。
底层是普通文件
Markdown、PDF 和 PNG 都放在文件夹里。可以一次选中多张卡片批量删除。

你不在时，它照常工作。

给一条提示词设定时间，之后再来看记录。每次运行都有自己的会话，无人值守的任务不会弄乱你的会话列表。

Cron 表达式
每天、每周、每月，可指定时区。停用任务后，历史记录依然保留。
无界面运行，全程记录
每次运行的提示词、工具调用和回答都会被记录，不需要打开浏览器。
同一个产物库
结果和其他产物一样保存，早上起来就在那里。

无论你在哪里，都是同一个助手。

在 Chrome 里

在任意页面旁打开 Zett，它能读取你正在看的内容。填写字段或点击按钮之前，会等你选择“仅此一次允许”“拒绝”或“本会话始终允许”，敏感字段则永远不会被触碰。

安装扩展

在微信里

用手机给 Zett 发消息。照片、语音和文件都会作为文件送达，你不在电脑前时，结果也会保存进产物库。

接入聊天应用

在终端里

Claude Code 或 Codex 刚完成的工作，可以通过命令行或 MCP 直接归档到产物库。

zett artifact create --type card \
  --title "发布说明" --body-file notes.md

在 Python 里

插件可以增加工具、钩子、Slash 命令，甚至整个聊天渠道。插件默认不受信任，所以一个出错的插件不会拖垮 Zett。

编写插件

一切都在一个文件夹里。

你的产物库、会话、文件和设置，都是磁盘上的普通文件。像对待任何文件夹一样备份、迁移或删除它们。唯一的网络流量只发往你选择的模型，只有接入聊天应用时才会连接对应平台。

没有你的许可，助手既不能删除任何东西，也不能操作网页。

~/.zettelekasten/

  • zett.db产物库、标签、设置
  • agent.db所有会话
  • artifacts/论文和生成的文件
  • assets/你添加的文件
  • skills/你可以编辑的指令
  • logs/出问题时查看

模型密钥在此文件夹中加密保存。

两条命令，即可开始。

Python 3.10 到 3.14。无需登录任何账号，也没有任何东西在云端运行。

$ uv tool install zettelekasten
$ zett start
Zett is running at http://127.0.0.1:6280
  1. 先启动一次。 zett start 会在后台运行工作区，zett status 可以查看状态。
  2. 接入一个模型。 在设置里添加模型服务，密钥会被加密并留在你的电脑上。
  3. 开始对话。 让它做一张卡片，在聊天旁边审阅，然后保存。
